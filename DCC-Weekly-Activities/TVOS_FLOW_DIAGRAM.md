## Navigation Flow:

```
Login Screen
    │
    ├─→ [Load Test Data] ─→ Dashboard (with mock data)
    │                           │
    │                           ├─→ Stats Tab (default)
    │                           │     │
    │                           │     └─→ Summary Cards
    │                           │          Leaderboard
    │                           │
    │                           └─→ Activities Tab
    │                                 └─→ Individual rides list
    │
    └─→ [Visit dcc.club...] ─→ (OAuth not available on tvOS)
```
