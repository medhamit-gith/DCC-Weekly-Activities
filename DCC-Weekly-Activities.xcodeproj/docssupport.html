Frequently Asked Questions

The app shows no data after logging in

Make sure you are a member of the Desi Cycling Club on Strava. The app only shows activities from that club. If you just joined, try pulling down to refresh from the main screen.

Login isn't working

Tap Log Out, then log in again. If the Strava login page doesn't appear, check that Safari is not blocked in Screen Time settings.

Face ID / Touch ID prompt doesn't appear

Go to iPhone Settings → DCC Weekly Activities and make sure Face ID permission is enabled.

Data looks out of date

Pull down on the main screen to force a refresh. The app fetches the most recent complete week (Monday–Sunday).
