🔒 Getting Into the App
1

Club Code Login

Enter your club code (DCC2026) and your name, then tap Enter.

2

Face ID / Touch ID

Authenticate with biometrics to unlock the dashboard. On subsequent launches you skip straight here.

3

Dashboard

You're in! 5 tabs across the top, your club data loads automatically from the server.

Logging out: Tap your profile avatar (top-right circle) → Log Out

📊 How to Read the Charts

Distance Bar Chart

Who rode the most this week
Longer bar = more km. Your bar is highlighted in orange.

Radar Chart

Your overall profile vs the club average
Bigger shape = stronger. Dashed line is the club average. If your shape is inside the dashed line, that's an area to improve.

Speed vs Elevation Scatter

Whether you're a climber, speedster, or all-rounder
Top-right = fast and climbing. Bottom-left = building endurance. Your dot is the largest.

Performance Zones

Who's best and worst in each metric
Green bars = top performers. Muted bars = room for improvement.
💡 Feature Requests
💡

Got an idea? Tell us from inside the app.

Tap the orange lightbulb button (bottom-right, visible on every tab) to open the feature request form. Type or use voice-to-text to describe your idea. It goes straight to our backlog.

✍️ Text Input

Type your request (10–1000 characters) with real-time character count.

Tap lightbulb → type

🎤 Voice Input

Tap the mic icon to dictate. Speech is transcribed in real-time. Edit before submitting.

Tap mic icon

60-second cooldown between submissions to prevent accidental duplicates.

Automatic

📶 Works Offline

💻 iPad Layout

Sidebar Navigation

4 tabs in a sidebar: This Week, Leaderboard, Insights, Analysis. Adapts live when resizing in Split View or Stage Manager.

Two-Column Main View

Left 2/3: podium (top 3) + full ranked table. Right 1/3: best ride card + highlight stats (longest ride, fastest rider, most active).

📚 What the Icons Mean
↑ Rode more than last week (>10% up)
↓ Rode less than last week (>10% down)
→ About the same (within 10%)
★ New rider — no previous data
🥇 Medal badges for top 3
🔥 Great performance
-23km Gap badge — distance to leader
⚠️ Offline & Error States
  • No internet on launchShows cached data or error screen with Retry button
  • Offline feature requestQueued locally, auto-sends on reconnect
  • No activities this week"No Activities Yet" empty state
  • Only 1 rider"Need More Riders" — comparisons need 2+
  • Biometric failsRetry button + log out option
  • Invalid club code"Contact your DCC admin for the correct code"
